# foto

A lightweight, private-in-browser photo enhancer. Open `index.html` directly, or run a local server:

```sh
python3 -m http.server 4173
```

Upload a photo, adjust exposure, contrast, saturation, warmth, and clarity, then download an enhanced JPEG. **Auto enhance** applies a gentle starting point; **Compare** temporarily shows the original. Images are processed locally in your browser and are never uploaded.
