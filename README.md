# foto

Фотографии

## Что в репозитории

| Папка | Что это |
| --- | --- |
| корень | оригиналы — чёрно-белые сканы, не изменяются |
| `color/` | раскрашенные версии в естественных тонах (плёнка 70–80-х) |
| `restored/bw/` | очищенные ч/б сканы: убрана пыль и царапины, приглушено зерно, выровнены пересветы и контраст, +резкость, 2× |
| `restored/color/` | то же самое для раскрашенных копий (цвет затронут мягко) |

## Скрипты

```bash
python3 make_restored.py                  # пересобрать restored/* и index.html
python3 tools_restore.py IN.jpg OUT.jpg   # один файл, режим определяется автоматически
python3 tools_restore.py IN.jpg OUT.jpg --mode=bw --scale=2 --denoise=4
```

Пайплайн (`tools_restore.py`):

1. `dust_scratch` — поиск мелких пылинок и тонких светлых царапин + inpaint;
2. `denoise` — шумоподавление с сохранением краёв;
3. `flatten` — частичное выравнивание вспышечных пересветов, засветов и виньетки;
4. `auto_levels` — растяжка тонов по перцентилям;
5. `keep_brightness` — гамма-возврат к исходной яркости (контраст растёт, экспозиция — нет);
6. `unsharp` — повышение резкости только по яркости, до апскейла;
7. `upscale` — Lanczos 2×;
8. `grain` — лёгкое зерно, чтобы не было «пластика».

Особенности:

* **Ч/б сканы обрабатываются на нейтральной копии яркости.** В скане каналы RGB не равны
  на пару единиц; при раздельной растяжке это превращается в цветные крапинки. Нейтральная
  копия даёт ровно ноль цветового шума, а исходный (обычно тёплый) оттенок возвращается
  множителями из `auto_tint` — не более ±10 %.
* **Цветные копии** не трогаются поканально: тон правится по L, а шум цвета гасится
  медианой по a/b, поэтому оттенки не «уезжают».
* Индивидуальные настройки на кадр — в словарях `BW_OVERRIDES` / `COLOR_OVERRIDES`
  в `make_restored.py` (например, у «Малыш в коляске» тонкий вязаный узор, ему нужен
  более мягкий denoise).

## Галерея

`index.html` — сравнение в три колонки: оригинал → очищенный ч/б → цвет.
Открыть локально:

```bash
python3 -m http.server 8080
```
