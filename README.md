# foto

A lightweight, private-in-browser photo enhancer. Open `index.html` directly, or run a local server:

```sh
python3 -m http.server 4173
```

Upload a photo, adjust exposure, contrast, saturation, warmth, clarity, sharpness, and noise reduction, then download an enhanced JPEG. **Auto enhance** uses image luminance percentiles for a gentle, photo-aware starting point; **Compare** temporarily shows the original. Images are processed locally in your browser and are never uploaded.
