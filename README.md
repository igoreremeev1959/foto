# foto

Фотографии

## Восстановление (`restored/`)

Старые сканы чёрно-белых отпечатков восстановлены скриптом `tools/enhance.py`
(Python + Pillow + NumPy). Оригиналы в корне репозитория не изменяются.

Что делает обработка для каждого снимка:

1. **Обрезка** белого поля сканера / края альбомного листа.
2. **Подавление зерна** сканера (медианный фильтр, частичное смешивание).
3. **Выравнивание освещения** — убирает засвеченные углы и виньетку,
   не меняя общую экспозицию.
4. **Тоновая коррекция** — растяжка чёрной и белой точки по перцентилям,
   вывод средних тонов в нужную зону, мягкое открытие глубоких теней.
5. **Локальный контраст** (CLAHE-подобный, по тайлам, с сохранением
   общей яркости) — возвращает детали в тенях и светах.
6. **Выравнивание контраста** между кадрами, чтобы серия выглядела ровно.
7. **Усиление резкости** (unsharp mask).
8. **Увеличение в 1.5×** (Lanczos) + лёгкий тёплый тон отпечатка
   и тонкая белая рамка.

Цветной «жёлтый» каст старых отпечатков при этом убирается: обработка идёт
по яркости, поэтому результат — чистый нейтральный ч/б без синих/жёлтых пятен.

Запуск:

```bash
pip install --break-system-packages pillow numpy
python3 tools/enhance.py . restored      # исходники → restored/
```

Можно менять параметры в начале скрипта (`SCALE`, `WARM`, `TARGET_STD`) —
`WARM` задаёт оттенок: `(1.0, 1.0, 1.0)` — полностью нейтральный серый,
текущее значение — чуть тёплый, как у бумажного отпечатка.

## Цвет (`color/`)

`color/` — колоризованные версии снимков (цвет добавлен ИИ, композиция,
лица и предметы не меняются). Для `изоб11`–`изоб16` — ранняя колоризация,
для `изоб17`–`изоб26а` — колоризация по восстановленным кадрам из `restored/`
в едином стиле «дачный цветной снимок 1980-х»: приглушённые натуральные цвета,
тёплый свет, лёгкое зерно, без перенасыщения.

| Папка | Что внутри |
|---|---|
| корень | оригиналы сканов (без изменений) |
| `restored/` | исправлены каст, контраст, резкость; 1.5× |
| `color/` | колоризация поверх восстановленных кадров |

Пока не колоризованы: `изоб27 001`, `изоб27а`, `изоб28` — будут добавлены
следующим заходом (лимит генерации изображений на один запуск — 10 штук).
